# Globe 頁面文字

Globe 頁面的地理圓點、天體選單、研究簡介、基本數據、段落、參考資料及閒聊對話都從本資料夾的 Markdown 讀取。儲存 Markdown 後，Vite 開發伺服器會自動更新頁面。

## 檔案位置

- `bodies/<id>.md`：各天體的標題、簡介、數據、段落和參考資料。
- `continents/<id>.md`：各洲的標題、簡介、數據、段落、參考資料及閒聊。
- `solar-system.md`：全體天體共用的閒聊內容，只維護這一份。

目前 Globe 有七個洲域圓點（包含南極洲），每份洲域 Markdown 都保留三個閒聊位置。

## 編輯簡介和其他文字

直接修改相應檔案的 `#` 標題、`## 副標題`、`## 簡介`、`## 基本數據`、各段落標題與 `## 參考資料`。請保留檔案最前方的 `id`、`name`、`order` 註記，以維持天體識別及原有排序。基本數據使用 `- **項目**：內容`，參考資料使用 `- [標題](網址) — 作者｜查閱：日期`。

## 編輯閒聊

每個對話以 `###` 後的識別碼開始，`####` 是頁面顯示的對話標題。請保留識別碼和順序，並以「角色名稱：台詞」格式逐行編輯：

```md
### asia-example

#### 對話標題

<!-- status: complete -->

角色名稱：台詞
另一位角色：台詞
```

未完成的位置使用 `〔待補充〕`。若位置標成 `<!-- status: draft -->`，補完台詞後將狀態改為 `complete`，它才會出現在頁面上；空白或草稿不會被當成可播放對話。保留台詞前後的標點與換行，對話會依 Markdown 行序逐句顯示。
