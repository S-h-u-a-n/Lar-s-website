# The Wizard’s GENESIS — Codex Edition

這是一份獨立的藝術互動網站實驗，保留原創插畫、模型、故事與既有內容。正式專案沒有被改寫，也沒有執行部署。

## 開啟

本資料夾使用自己的 package-lock.json 與依賴，沒有連結原專案的 node_modules。

```sh
npm ci
npm run dev
```

開啟 http://127.0.0.1:5186/ 。已安裝依賴時可以直接執行第二行。連接埠採 strictPort；被佔用時請先關閉同一實驗版本的舊伺服器，避免把原版當成副本。

正式建置與預覽：

```sh
npm run build
npm run preview
```

開啟 http://127.0.0.1:4186/ 。預覽只綁定本機，不會發布到 GitHub Pages 或覆蓋正式網站。

## 調整位置

- `src/edition/config.js`：工具名稱／路徑、桌邊小物、故事圖層節奏、翻頁時間與工具物理回饋參數。
- `src/edition/edition.css`：這份版本的色彩、排版、紙片、鏡片、響應式與微動畫。
- `src/components/main/revealConfig.js`：五次揭幕、圖片臉部相對位置、色盤、格子、時間與翻格波浪。
- `Art/Edition`：從三張原始差分縮製的 2400px 寬度預覽版本。原始三張圖片仍在 `Art/Main-art`。

未新增動畫函式庫。採用原本 React、Vite、Three.js、Framer Motion、MapLibre；保留既有第三方授權檔及字型 OFL。

## 內容與實測限制

- 未完成的文章、學生推薦、來信／日誌與部分介紹卡仍是原本的開發內容，沒有為了填滿版面擅自編寫新世界觀。
- Favorites 的漫畫紙版是裝飾，不是 Mira／Theo 的正式肖像；Live2D 模型仍未接入。
- 未完成、沒有分鏡的工具漫畫會直接進入其已有研究頁；原程式和內容仍保留。
- Telescope 的第二種模式是衛星地形，而不是街景。地圖依賴外部供應商與網路。
- 原始模型與中文字型仍偏大。已縮製主視覺，並排除未使用的重複字重檔，但沒有破壞原始模型或重製插畫。
- 已用 Chrome 實測主要流程及多種桌面比例；尚未實測 Safari、Firefox、觸控及完整螢幕閱讀器流程。
- 裝飾動態、轉場與揭幕尊重 reduced-motion；原專案的部分鏡頭聚焦動作仍保留。
- 探索記號是本次操作期間的狀態；本機收藏依不同 port 的瀏覽器來源隔離。測試來源 5186 留有一筆明確標示的 QA 收藏，原版來源的收藏沒有被讀寫。

## 原版隔離驗證

```sh
python3 scripts/verify-original.py
```

此命令只讀取原版：比對開始工作時的 333 個檔案 SHA-256、大小、修改時間及 Git 狀態，將結果寫到本版本 `docs/original-isolation-verification.json`。它不會修復、清理或改動原版。

完整實測紀錄與截圖見 `docs/Codex-Edition-verification.md`。
