# 拼圖畫廊

## 設計與素材

主頁角色區後、許願區前保留獨立收藏區。採低飽和粉色、深淺實色側邊、奶油白襯紙與四角菱形結構，取消金屬漸層；框體有輕微透視與拿起回饋。共用網站的字體變數、幾何細節、錯位陰影與 Framer Motion。

素材保持 `Art/Main-art/Mainart.JPG`，JPEG，8994×4048。未修改原檔、裁切或拉伸，也未新增生成素材。遊戲內等比例建立最大邊 2560px 的記憶體 Canvas，避免每片反覆繪製 8994px 原圖。主頁未解鎖時不建立作品 img，框口維持原圖比例，只顯示灰底問號。

遊戲採暖白連續工作桌，先分配作品框可用寬高，再放散片；不以完整攤開所有拼片作為縮小中央作品的理由。低矮視窗縮短標題與工具列，窄版工具分兩列，新局散片放到作品下方。桌面可自由平移、縮放與總覽；跨視窗載入舊局不會自動打散已有位置。

## 操作與收藏

- 拖曳拼片／群組自由拼接，正確相鄰邊可在桌上任何位置接合。
- 單片或群組靠近棋盤正確位置後固定；接上固定群組也會固定。已定位群組不再被誤拖走，點擊仍提供回饋。
- 吸附半徑依 CSS 螢幕像素換算：滑鼠最大 11px、觸控最大 15px，並限制為拼片短邊的四分之一。只吸附最近有效候選，後續連鎖只合併已經精準對齊的鄰片，避免遠距拉動。
- 點選拿起會帶整組到最上層；「翻找散片」循環所有未定位拼片（包括完全被蓋住的），必要時平移到可見處。「展開散片」只整理獨立散片，不破壞已接合群組或固定位置。
- 拖曳空白處／滾輪平移；雙指縮放與平移，Ctrl／Command＋滾輪縮放。工具列提供置中、縮放與全部拼片總覽。
- Canvas 取得焦點後：空白鍵翻找，方向鍵移動，Shift 精細移動，Enter 接合／定位，Escape 取消拖曳。按鈕、難度選單、原圖預覽與原生 dialog 均可用鍵盤操作。
- 難度切換先保存並確認，各難度分別保存；重新開始有另一個確認流程，只重設當前難度。
- 完成時接縫約 450ms 淡出，作品回到中央並完整展示約 2 秒，再開啟作品介紹。可提前點「欣賞作品」。已完成存檔重載不重播自動彈窗。
- 已解鎖主頁畫框開啟共用作品介紹視窗，另提供「再次拼圖」。視窗以大圖優先，可切「只看作品」；正式名稱、主題、背景、感言、作者、年份僅在資料提供時出現，不放空白佔位或編造內容。
- 保留原有 App 轉場、選中作品、返回捲動位置與焦點，以及 HomeGeometry 左側避讓路徑。只一幅作品時，左右箭頭停用。

## 保存與相容

維持原有 `genesis:puzzle:v1:<art id>:<art version>:<difficulty>`、解鎖與最後難度鍵名；未清除舊資料或改引擎版本。

新增 `layout: gallery-table-v2`、`order` 與各位置的 `locked`。沒有 layout 的舊保存依舊棋盤原點（300,120）轉換座標，保持群組相對位置；舊群組不會強行拆散。載入檢查群組連通、相對幾何、固定位置與層序；無效資料不採用。完成任一難度的收藏紀錄獨立保存，重新開始不會取消解鎖。瀏覽器清除網站資料後，本機進度仍會消失。

## 維護位置

- `artworks.js`：穩定 ID、版本、原比例、URL、難度、frame 類型與可選介紹欄位；新作品沿用同結構，構圖變更時增加作品版本。
- `engine.js`：共享凹凸邊、群組、吸附、固定、散片、完成判定與舊資料驗證。
- `usePuzzleTable.js`：獨立的相機／輸入／Canvas 繪製，拖曳直接更新模型，無持續空轉繪製；只有進場、吸附、鎖定與完成時安排動畫幀。
- `progress.js`：本機進度／收藏；`PuzzlePage.jsx`：工具、確認、載入、完成計時。
- `PuzzleDialog.jsx`：原生 dialog 焦點與 Escape，加上進出場／遮罩動畫；`ArtworkDialog.jsx`：遊戲與主頁共用的作品展示。
- `PictureFrame.jsx`、`PuzzleGallery.css`：畫框 renderer 邊界與統一視覺；未引入 WebGL，日後 GLB 可替換 frame 內部。
- `HomePuzzleGallery.jsx`：主頁收藏入口；`App.jsx`、`HomeGeometry.jsx` 保留第一版整合。

## 新增一幅插畫

1. 將作品原圖放入 `Art/Main-art/`，保留原始比例並使用不重複、容易辨認的檔名。
2. 在 `src/components/puzzle/artworks.js` 匯入圖片，並在 `ARTWORKS` 陣列新增一筆設定。每筆設定提供唯一且穩定的 `id`、`version`、`number`、`title`、`src`、原圖像素 `width`／`height`，以及三種 `difficulties`／`difficultyNames`。
3. 暫無資料的 `officialTitle`、`theme`、`description`、`artistStatement`、`year`、`artist` 維持 `null`，作品介紹視窗會自動略過空欄位。
4. `id` 用來隔離每幅作品的進度與解鎖；更新插畫構圖或尺寸時增加該作品的 `version`，不要重用其他作品的 ID。

例如先匯入 `import newArt from '../../../Art/Main-art/new-art.jpg'`，再複製既有作品設定為新物件，更新 ID、編號、標題、圖片、實際尺寸及作品資訊即可。作品會自動加入左右切換、獨立拼圖與收藏畫廊，不需修改元件或樣式。

沒有複製 Resla/jigsaw 程式碼或素材，也未新增相關依賴。減少動態設定停用位移、縮放與接合補間，仍保留完整作品的欣賞時間。

角色集合自動收錄 Art/avatar 目前 27 張 JPG（皆 2048×2048），名稱取自檔名、ID 使用 `genesis-avatar-<檔名>`。新增相同尺寸頭像只需放入該資料夾；若未來尺寸不同，請在統一配置更新該頭像尺寸。角色檔名是存檔識別的一部分，有既有進度後不要任意改名。一般插畫仍只需新增 ARTWORKS 資料。

集合不另存一份完成旗標，而是由子項的永久收藏紀錄推導。每個子項仍按 ID／版本／難度保存位置與最後選擇的難度。重新開始只重設當前難度位置，不撤銷收藏或完整長圖解鎖。返回畫廊時，子項 ID 會對應回所屬集合，左右切換仍只計五個位置。
