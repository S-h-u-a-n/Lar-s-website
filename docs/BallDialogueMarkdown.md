# BallTest 對話管理

對話來源位於 `content/ball/dialogue/`，由 Vite 以原始文字載入，不需新增套件。

- `opening.md`：每次進入頁面時播放的開場。
- `movies.md`、`games.md`、`anime.md`、`literature.md`、`performing-arts.md`、`music.md`：各分類作品對話。

## 編寫方式

在作品的 `<!-- workId: ... -->` 下方填寫，例如：

```text
拉爾（6/52）
「第一行台詞
第二行台詞」

拉爾（7/38/4）
「可以讓同一角色連續發言。」

緹芙波（3/34/1）
「另一位角色的台詞。」
```

數字依序為身體、表情、轉場編號；第三碼省略時為 0。0–4 直接沿用既有立繪轉場，不根據台詞或素材變化推斷效果。同一差分再次指定轉場也會執行。保留中文引號與台詞內換行。

每件作品使用 `## 作品名稱` 分區，必須保留唯一且正確的 workId 註解；修改標題不影響對應。不要將同一作品拆成多個重複 ID 區塊。HTML 註解只作編輯說明，不會顯示。

尚未編寫的區塊可保持只有標題與 workId；空白角色行及空的 `「」` 亦會略過。作品資訊文字仍由原本資料來源管理。

## 操作

進頁播放開場，兩個角色的對話框均可點擊逐句繼續，最後一句點擊後結束，不會自動開啟作品資訊。

滑鼠移入或鍵盤聚焦作品卡片都不會展開。第一次點擊（或 Enter／Space）會選取並展開作品，同時開始該作品的 Markdown 對話；沒有台詞則保持展開，不顯示空白對話框。再次點擊同一張已展開卡片，立即開啟原本作品資訊視窗，不重播對話。點擊其他作品則收回舊卡片，展開新作品並重置對話。關閉資訊視窗後仍保留展開狀態。

作品索引選取會定位並展開該作品、開始對話。Previous／Next 每次將三件作品的可視視窗移動一件，例如 A/B/C → B/C/D → C/D/E；反向按鈕往回滑動。選取位置同步移動一件，自動展開並重置為該作品的對話，不會開啟詳情。首尾沿用原本程式的循環邊界。再次點擊已展開卡片才開啟詳情。

側邊進度顯示視窗起始作品的位置，可直接定位；分類切換會清除展開及對話。動畫使用持續遞增／遞減的邏輯位置識別卡片，保留仍在視窗內的作品，不以三件為一組重新掛載。快速連按會從最新導航狀態計算，舊卡片離場期間停用點擊與鍵盤聚焦。

切換分類、作品選取或點擊另一件作品會中止舊對話。切換會更新立繪 cue 身分，交由既有轉場管理器取消未完成的動畫與素材請求。

未知、重複、遺漏 workId，以及無效差分／轉場會在主控台輸出 `[Ball dialogue]` 診斷；錯誤作品區塊不會借用其他作品的台詞或阻止作品資訊顯示。

## 驗證

執行 `node --test src/components/ballTest/*.test.mjs` 與 `npm run build`。
