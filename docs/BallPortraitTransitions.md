# BallTest 角色差分與轉場

## 台詞輸入

作品的 `dialogue` 可直接設定為以下多行字串（以下只作格式示例，未加入正式台詞）：

```text
拉爾（6/52/3）

「總之就是這樣子！我們兩個要努力地向大家分享我們喜歡的作品！！」

緹芙波（3/34/1）

「沒錯！」
```

格式為 `角色名稱（身體編號/表情編號/轉場編號）`。第三個數字省略時為 0。身體編號按照 `Art/ball/web/characters.json` 的 poses 順序，表情使用既有數字素材。台詞文字與標點不會被改寫；兩個角色的姿勢分別延續至各自的下一句。

既有台詞物件陣列繼續可用，也可寫成 `{ speaker: '拉爾（6/52/3）', text: '…' }`，或 `{ speaker: 'lar', body: 6, face: 52, transition: 3, text: '…' }`。舊 `expression`／`motion` 欄位不會推測、選擇或覆蓋數字轉場。

## 五種模式

| 編號 | 模式 | 時長 | 替換時點 |
| --- | --- | --- | --- |
| 0 | Cut | 0ms | 素材解碼完成後直接替換 |
| 1 | Flash | 200ms | 前 60ms 用 #fffdf9 覆蓋框內全部內容，在完全覆蓋時換差分，再用 140ms 退去覆蓋層 |
| 2 | Crossfade | 200ms | 舊／新完整立繪同步交叉淡化 |
| 3 | Pop | 420ms | 開始時替換，整框連同內部內容三次遞減上浮／放大，最後恢復 |
| 4 | Shake | 220ms | 開始時替換，整框連同內部內容輕微左右震動後恢復 |

所有模式共用 `portraitTransitions.js` 控制器，使用 Web Animations API；沒有新增套件或延遲計時器。1 號驅動既有內部 alpha 遮罩中的奶白覆蓋層，位於角色／內部背景之上、獨立外框之下，沿用原始背景輪廓與圓角，不使用近似的矩形裁切。3／4 號驅動包住整張 SVG 的 `ball-portrait-component`，外框、背景、角色與陰影同步移動。0／2 號維持原有身體／表情處理。原定位容器與浮動容器不被覆寫，動畫結束或取消後清除填充效果，恢復原始位置與大小。指定模式不因內容、情緒、素材是否變更或 reduced-motion 偏好而改號／略過。

每句的 `cueKey` 包含作品與角色最近一句的索引。因此相同素材連續出現時仍會重新執行指定動畫，另一個角色說話則不會重播此角色的動畫。

## 解碼與快速操作

新身體與表情必須都成功解碼，才開始轉場；等待時保留目前立繪，台詞操作不等待解碼或動畫。新請求立刻取消舊動畫，去掉所有過渡樣式與舊交疊層，並用版本號忽略過期的解碼／動畫完成通知。Flash 覆蓋層的靜態 opacity 為 0，取消後即恢復隱藏；若尚未到替換點就被取消，保留原本立繪；已替換的模式則保留最新立繪。離頁取消後不再更新 React。

開發模式的既有「角色素材測試」面板提供 0–4 選單與「重播轉場」，可測相同素材重播。正式台詞及作品資料未修改。

## 驗證

```sh
node --test src/components/ballTest/*.test.mjs
npm run build
```

`portraitTransitions.test.mjs` 使用可控制完成／取消的動畫替身，涵蓋五種模式、四種素材變化、首次顯示、Flash 中途取消、Crossfade 中斷、解碼競態、錯誤與卸載；原有 `characters.test.mjs` 確認 1000 組素材的 SVG 合成位置及圖層順序。這些測試不等同瀏覽器逐幀視覺驗證；本次瀏覽器存取服務不可用，尚未完成實際動畫觀感檢查。

先前針對轉場、素材與既有對話的 30 項測試通過，建置通過。先前擴大執行整個 BallTest 測試集為 40/41 通過：既有 `posterSources.test.mjs` 的「new works have no invented copy」要求部分作品 `dialogue=[]`，與目前 `data.js` 已存在的三句對話不一致；本次沒有修改作品資料或該測試。

目前 Flash 不使用角色濾鏡或交叉淡化，覆蓋層在換圖時保持完全不透明。Pop 三次抬升比例為 1／0.55／0.22，放大倍率為 1.025／1.014／1.006；Pop／Shake 的整體位移使用 CSS 像素，最大 5px，不沿用原始大圖的座標單位。仍使用同一套控制器、版本號及取消機制。

本輪 35 項相關測試通過，包含整框／框內作用域、奶白層位置與隱藏基準，以及所有動畫模式間的快速切換。瀏覽器逐幀視覺驗證尚未完成。
