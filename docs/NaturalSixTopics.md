## 合併

- 生物演化＋生物適應 → **生物演化與適應**：一起說明族群跨世代改變及自然選擇、環境取捨，並保留漂變、基因流動與非適應特徵的限制說明。
- 生態系統＋食物網 → **生態系統與食物網**：先談生物、環境及物質循環，再以攝食關係說明能量傳遞；保留系統擾動、邊界及能量比例不能一概而論的內容。
- 生物多樣性＋生態保育 → **生物多樣性與保育**：由基因、物種及生態系統層次，連到威脅、棲地管理、監測與地方參與。
- 恆星的形成與演化＋黑洞與重力證據 → **恆星演化與黑洞**：從恆星形成、主序到殘骸，再延伸至黑洞的觀測證據。黑洞的銀河系中心觀測、重力波、影像與未解問題全部保留，沒有縮成一句「恆星死亡後形成黑洞」。

四篇合併文章各保留原兩篇的導言、全部四個知識段落及所有不重複來源。原文保存為 `SOURCE_ARTICLES`，公開卡片使用整理後的 `ARTICLE_LIST`；`topicIds` 記錄每篇內容來自哪些舊主題，便於驗證及後續編輯。不是只隱藏原卡片而丟失正文。

## 拆分與不調整的分類

- 岩石與礦物 → **岩石與岩石循環／礦物與辨識**：岩石談類型與形成過程；礦物談結構與物理辨識，原本的樣本例子及辨識線索分別保留。
- 河流與湖泊 → **河流與流域／湖泊與內陸水域**：區分沿河道的搬運與侵蝕，以及湖盆、鹽分與混合環境，原段落保留並補上各自需要的說明。
- 氣候與季節 → **氣候與長期變化／季節與日照**：區分長期統計與年內日照節律；原有氣候判讀、軸傾角、南北半球及乾濕季內容均保留。NASA 季節連結移到季節文章，不放在氣候統計文章。
- **植物與真菌**原本已有六篇，內容分工明確，維持不變；傳粉生物仍在此類。

沒有再把主題搬到不適合的分類，也沒有加入全新的無關主題湊數。拆分後補充內容核對了 [Rock (geology)](https://en.wikipedia.org/wiki/Rock_(geology))、[Mineral](https://en.wikipedia.org/wiki/Mineral)、[River](https://en.wikipedia.org/wiki/River)、[Lake](https://en.wikipedia.org/wiki/Lake)、[Climate](https://en.wikipedia.org/wiki/Climate)、[Season](https://en.wikipedia.org/wiki/Season)。維基百科來源查閱日更新為 2026-11-07，未在本次重查的 NASA 連結維持原日期。
