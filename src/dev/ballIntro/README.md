# BallIntroTest：魔法收藏架組裝

開發網址：<http://127.0.0.1:5186/Lar-s-website/?dev=ball-intro-test>。沿用既有 `npm run dev`（5186），不需新啟動服務。這是 DEV 專用入口，正式 App／BallTest 開場流程未修改，正式 build 不包含本試演模組。

## 演出與操作

總長約 3.35 秒，所有段落交錯執行：

- 0–1.7 秒：薄荷／粉色幾何旋入、細線魔法印展開，標題從斜上方回旋落位。
- 0.41–2.12 秒：兩個角色框分別由自己的外側下方旋入，帶輕微過衝回彈。
- 0.7–2.45 秒：三張現有海報由畫面中心洗牌、扇出、沿弧線歸位。
- 1.82–3.35 秒：分類與翻頁控制交錯到位，對話框落下；幾顆短暫星芒收尾後完全移除。

下方測試工具提供「重新播放」、「跳過」及「正常頁面」入口。重播重新掛載同一個 BallTest，恢復一致的初始收藏架；完成後可正常使用原頁面的作品、對話與角色差分功能。測試工具本身是覆蓋層，不改變頁面尺寸。

播放前等待兩位角色、框飾、當前三張海報與字型準備好。載入失敗時露出原頁面及重試功能，不會永久停在隱藏畫面；準備期間也能跳過。背景分頁暫停／回來接續。播放途中 resize 則結束試演、交回當下正常的響應式版面；開啟「減少動態效果」時直接顯示正常頁面。

## 技術與隔離

使用既有 React／BallTest 與瀏覽器 Web Animations API，沒有新套件、新圖片或正式台詞修改。`introChoreography.js` 量測現有元素，再依 viewport 安排相對軌跡；`introPlayback.js` 將 transform 以 additive composite 疊加，避免覆寫 Framer Motion、原立繪定位或浮動 transform。透明度獨立處理，保留裝飾的原本透明度。結束、跳過、重播及卸載都取消全部開場效果，並非留下計算過的像素落點。

測試 CSS 全部限定於 `.ball-intro-test`。只在試演中取消原有短進場動畫、暫時解除海報視窗裁切；正常狀態恢復裁切。角色差分動畫繼續使用原本的內部／整框系統，沒有修改它的程式。

## 檢查

```sh
node --test src/dev/ballIntro/intro.test.mjs
npm run build
```
