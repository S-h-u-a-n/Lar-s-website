## 模擬方式

世界為 210×170，共 35700 格；Canvas 2D 顯示當前 TypedArray 資料，沒有地形 PNG、偽 3D 投影或預製天氣動畫。八種非空材料：土壤、岩石、水、雪、冰、岩漿、蒸氣、雲，空氣格可容納移動物質。

每格以 Uint8Array 保存材料／紋理／原始地層來源，Float32Array 保存溫度／土壤濕度，Uint16Array 保存年齡／浸水時間，Uint32Array 保存本步更新標記。自下往上更新，交替橫向掃描；交換與轉換標記兩格，避免一粒在同一步被重複處理。固定 30Hz，最多追算三步，隱藏分頁暫停；Canvas 更新不經 React，React 約每 0.18 秒才接收小型讀數與筆記快照。

- 水向下、沿斜坡和橫向空格移動，水平路徑逐格檢查，不能穿牆。水位由真實連續水／冰格測得，沒有替場景設定一條假水面。
- 土壤受重力、濕潤與支撐影響，比連續岩層不穩定。原岩層在長期浸水或熱衝擊後崩解成土粒；新冷卻岩石會沉入水中並堆積。
- 雪下落、堆積、壓實；低溫由水面／冰鄰格向內凍結，正溫逐格融回水。
- 陽光增加全域溫度與光照，各格逐漸交換熱量；熱水表面轉成上升蒸氣，蒸氣冷卻成雲，密集且成熟的雲格轉為雨／雪。
- 岩漿慢流，接觸水、冰、雪時對方轉蒸氣，岩漿轉岩石。接觸在移動前從雙方判定，避免掃描順序漏反應。附近地層會受熱。
- 風影響空中粒子與海面。強風＋近期雨水＋足夠雲量產生渦旋風場，真實移動雲、雨與蒸氣；不是一張颱風動畫。
- 雲量來自實際雲格數並影響遮光。彩虹是光照／水氣條件驅動的輕量色帶，可用彩虹瓶促進。

水、雪、冰、蒸氣、雲每格都代表一份水。材料轉換／交換保存這些水格；只有按住雨、冷、雲藥水時新增外部水分。邊界封閉，不讓水氣無限消失。岩漿遇水的反應也保存那一格水。土壤濕度是獨立的簡化濕潤指標，沒有納入完整含水量或能量守恆。

## 操作

保留瓶子選擇、拖到世界並長按、直接按住世界、聚焦世界按住 Space／Enter，放開／Escape／失焦立即停止。雨雪從天空落下並跟隨落點的橫向位置；岩漿從指標位置附近的空格倒入，點到水或地層時會找上方空格，不覆寫既有材料。兩種份量仍為 45%／100%。

停止後沒有延遲藥水輸入或新增投入量；已存在的材料、風勢、熱量、自然雲雨繼續演變。不是要求停手後所有自然現象立即消失。

## 五種小事故

先留 75 秒自由實驗，條件另外持續成立 8 秒。以下使用「放手一倒」，從新世界開始，時長僅供重現檢查，不是固定玩法配方。

| 結局 | 實際判定 | 重現操作 |
| --- | --- | --- |
| 諾亞方舟 | 大部分原陸地被吞沒、海面升高超過世界高度 23%、仍快速上升，冰和破壞不足以混淆 | 持續雨水，約 83 秒 |
| 冰河世紀 | 低於 −22°C，水體結冰 >88%，山坡雪覆蓋 >20% | 持續寒冷，約 83 秒 |
| 撒哈拉大沙漠 | 高於 50°C，乾燥土壤 >86%、平均水分 <12%、液態水剩不到初始 20% | 持續陽光，約 83 秒 |
| 失落的亞特蘭提斯 | 陸地流失 >45%、實際岩層侵蝕 >2.5%、海面趨穩，尚未嚴重熱崩塌 | 雨水 30 秒後放開，總時間約 110 秒 |
| 2012 世界末日 | 真正崩解的岩層 >52%，且至少兩種實際災害歷史成立（冰封、高溫乾燥、乾旱、洪水、岩漿） | 陽光到約 49°C、寒冷到約 −15°C，交替至地形崩塌，約 90 秒起 |

隱藏結局沒有專用觸發按鈕或瀏覽器測試捷徑。資料與粒子在結局凍結，原有小卡片只在中央沙盒內顯示，背景模糊／降對比。按「啟用回溯魔法」建立同種子初始世界，清空本輪筆記與狀態。

## 還是簡化的部分

沒有真實壓力／流體力學、應力求解、熱容量守恆或氣象模型；冰與雪同格水量，省略真實體積與密度差。風場是條件驅動的簡化渦旋，彩虹／太陽為光學視覺，不是物理材料。雲與蒸氣採少量離散格子，形狀偏粒子化。這些不影響真實水格移動、堆積、相變與岩漿接觸反應；核心沒有用預製動畫代替。
