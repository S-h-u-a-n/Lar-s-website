## 模擬方式

世界為 210×170，共 35700 格；Canvas 2D 顯示當前 TypedArray 資料，沒有地形 PNG、偽 3D 投影或預製天氣動畫。八種非空材料：土壤、岩石、水、雪、冰、岩漿、蒸氣、雲，空氣格可容納移動物質。

每格以 Uint8Array 保存材料／紋理／原始地層來源，Float32Array 保存溫度／土壤濕度，Uint16Array 保存年齡／浸水時間，Uint32Array 保存本步更新標記。自下往上更新，交替橫向掃描；交換與轉換標記兩格，避免一粒在同一步被重複處理。固定 30Hz，最多追算三步，隱藏分頁暫停；Canvas 更新不經 React，React 約每 0.18 秒才接收小型讀數與筆記快照。

- 水向下、沿斜坡和橫向空格移動，水平路徑逐格檢查，不能穿牆。水位由真實連續水／冰格測得，沒有替場景設定一條假水面。
- 土壤受重力、濕潤與支撐影響，比連續岩層不穩定。原岩層在長期浸水或熱衝擊後崩解成土粒；新冷卻岩石會沉入水中並堆積。
- 雪下落、堆積、壓實；低溫由水面／冰鄰格向內凍結，正溫逐格融回水。
- 陽光增加全域溫度與光照，各格逐漸交換熱量；熱水表面轉成上升蒸氣，蒸氣冷卻成雲，密集且成熟的雲格轉為雨／雪。
- 岩漿慢流，接觸水、冰、雪時對方轉蒸氣，岩漿轉岩石。接觸在移動前從雙方判定，避免掃描順序漏反應。附近地層會受熱。
- 風影響空中粒子與海面。強風＋近期雨水＋足夠雲量產生渦旋風場，真實移動雲、雨與蒸氣；不是一張颱風動畫。
- 雲量來自實際雲格數並影響遮光。彩虹是光照／水氣條件驅動的輕量色帶，可用彩虹瓶促進。

水、雪、冰、蒸氣、雲每格都代表一份水。材料轉換／交換保存這些水格；只有按住雨、冷、雲藥水時新增外部水分。邊界封閉，不讓水氣無限消失。岩漿遇水的反應也保存那一格水。土壤濕度是獨立的簡化濕潤指標，沒有納入完整含水量或能量守恆。
