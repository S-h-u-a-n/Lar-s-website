# Bottled Weather / 魔法天氣藥水

新版主專案：`GENESIS-Codex-Edition`。執行 `npm run dev`，開啟 http://127.0.0.1:5186/weather-potions.html 。獨立 DEV 入口，沒有接入 Big、正式導覽或正式建置。

沿用 Codex Edition 正式字體、配色、紙頁、左側標題／裝飾、中央框及右側筆記。本次保留 52×52 高度地形與水流／海面模型，只將地景渲染改為可替換透明 PNG 圖塊，沒有整張背景島嶼圖片。

## 操作與自由實驗

- 七瓶：雨水、陽光、寒冷、風、多雲、岩漿、彩虹。預設「一小口」45% 強度；「放手一倒」100%。
- 選瓶後按住世界，或拖瓶到世界並保持按住；放開停止。聚焦世界後可按住空白鍵／Enter。
- 拖出世界、取消指標、Escape、失焦、隱藏分頁皆停止輸入。隱藏分頁暫停模擬，不追算背景時間。
- 放開後不再新增該藥水投入量；既有水、雪、風、雲、岩漿和彩虹繼續流動、融化、冷卻或消散。
- 雨水沿坡流入海洋；陽光促進蒸發、融冰和乾燥。高山較冷，可以先出現山頂雪。
- 風移動雲與粒子、增強海浪及蒸發；強風＋雨水記憶＋雲量形成暴風雨。多雲遮光並減弱陽光升溫。
- 雨後放晴自然形成彩虹，彩虹瓶也可直接增加彩虹。岩漿沿坡流動，遇水冒蒸氣，冷卻留下會增加局部高度的岩石。
- 觀察筆記按實際現象解鎖。開發觀測提供風雲、粒子、岩漿、PNG 載入等讀數。

## 五種小事故

至少先經過 60 秒自由實驗；極端條件還須持續成立。短時間交替七瓶不會立即結束。以下為「放手一倒」、中央落點的測試操作，不是固定配方；實際時間依環境而異。

| 結局 | 環境條件 | 可重現操作 |
| --- | --- | --- |
| 諾亞方舟 | 雨水總量 ≥12000、海面 ≥42、淹沒 ≥88%、仍急速上升，持續 10 秒 | 持續雨水約 114 秒 |
| 失落的亞特蘭提斯 | 平均侵蝕 ≥4.2、淹沒 ≥70%、海面不急升，持續 12 秒 | 雨水 30 秒後放開，總時間約 117 秒 |
| 冰河世紀 | 氣溫 ≤−22°C、結冰 ≥96%、霜雪 ≥94%，持續 12 秒 | 持續寒冷約 72 秒 |
| 撒哈拉大沙漠 | 氣溫 ≥55°C、沙漠化 ≥92%、水分 <8%，持續 12 秒 | 持續陽光約 72 秒 |
| 2012 世界末日 | 多次熱衝擊導致平均地形損傷 ≥86%，持續 5 秒 | 陽光至 ≥49°C、寒冷至 ≤−13°C，交替三輪後放開 |

洪水與慢性沉沒要求地形損傷 <50%，避免與崩塌混淆，一次只觸發一個結局。結局凍結當時世界，僅在中央框內柔化背景並顯示小卡片，不是全頁 Modal；左側與筆記仍可閱讀。「啟用回溯魔法」恢復初始世界與空白筆記，回溯動畫也限制在框內。右側一般回溯入口保留。

## 簡化與效能

Canvas 2D 等角投影，不增加引擎或依賴。水沿鄰格流動，海面由地形容量求得；冷卻岩漿增加高度，侵蝕／熱衝擊降低高度。風、雲、暴風雨和彩虹使用簡化條件，沒有真實流體、氣象或完整大氣水量守恆。彩虹是共享環境驅動的像素色帶，蒸氣為可見示意粒子。

活動雨／雪／岩漿上限 320、蒸氣上限 100；模擬 30Hz、地形快取 10Hz、UI 約 6Hz、最多追算三步、DPR 上限 2。側面使用重複紋理，避免大量逐層繪製。結局、隱藏分頁與卸載皆清理迴圈。不讀寫 localStorage／sessionStorage。
