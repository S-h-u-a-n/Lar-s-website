# 手繪地形圖塊規格

透明 PNG 是一格格素材，由程式重複拼出山海，不要畫整張島嶼或整片背景。地形高度、水位和天氣與圖片分離。

## 先畫六張就能開始

第一批建議：**草地、石頭、沙地、海水、共用左／右側面，共六張**。其他保留臨時素材，逐張換即可。乾草可由草地改色、玄武岩可由石頭改色，右側面可鏡像左側面再壓暗；不用每格或每種高度畫一張。

| --- | --- | --- |
| `grass.png` | 64×32 | 草地頂面 |
| `rock.png` | 64×32 | 高山岩石頂面 |
| `sand.png` | 64×32 | 海岸、沙漠頂面 |
| `water.png` | 64×32 | 海洋頂面，不畫固定海岸或大浪 |
| `side-left.png` | 64×64 | 共用左側土石紋理 |
| `side-right.png` | 64×64 | 共用右側紋理，建議略暗 |

## 視角、頂面與側面

統一 **2:1 等角俯瞰菱形**，透明 RGBA PNG，建議 8-bit 每色頻道。保留完整畫布，不裁切透明邊界，不加白底。以最近鄰縮放顯示，每格約 13×6.6 邏輯像素；紋理要簡潔清楚，可先大尺寸繪畫再縮回指定尺寸匯出。

**頂面 64×32**：四角 `(32,0)`、`(64,16)`、`(32,32)`、`(0,16)`，中心錨點 `(32,16)`。實色填滿菱形內部，菱形外透明。不要把側面、山峰、樹木或投影畫在頂面；山峰由高度格點組合。不用四邊深色框，避免拼接像棋盤。

**側面 64×64**：同樣錨點 `(32,16)`，只畫以下四邊形，其餘透明：

- 左側：`(0,16) → (32,32) → (32,48) → (0,32)`。
- 右側：`(32,32) → (64,16) → (64,32) → (32,48)`。

側面是一段 **16px 垂直重複單元**。程式會去除斜切、沿垂直重複，再裁切到高度，因此矮坡與高山重用同一對圖片。不要畫不可重複的大圖案、強烈上下框；不用每種頂面另畫側面。建議左亮右暗，整套保持相同光源。

**覆層 64×32**：同一菱形與中心錨點。雪是半透明白色碎紋，雪量由程式透明度漸變；水窪在中央；泡沫只畫左上邊 `(0,16) → (32,0)`，其餘透明，程式翻轉組合岸線，無須為每個轉角畫圖。

水面高度、積雪、濕潤、凍結、乾燥由模擬決定。側面自動延伸；雨雪、雲、蒸氣、彩虹、海浪亮點仍程式繪製，不必畫逐幀動畫。

## 如何放置與替換

1. 放到 `src/dev/weatherPotions/tileset/`，使用上表同名 PNG。
2. 可先只換 `grass.png`，保留尺寸／透明／錨點／菱形，不改 JavaScript。
3. 開 `npm run dev` 與 `/weather-potions.html`，重新整理，確認「開發觀測 → PNG 圖塊」為 `14 / 14`。
4. 試雨、冷、陽光，確認變化後仍對齊。白縫通常來自菱形內透明邊距或匯出時裁切透明畫布。
5. 新檔名／變體在 `tileset.js` 管理；環境使用哪種頂面／覆層在 `tileState.js` 管理，不需重寫 `simulation.js`。更換整套投影／側面幾何時才需調整 `config.js`、`tileset.js`、`renderer.js`。

臨時產生器 `make-placeholder-tiles.py` 預設只補缺少的檔案。**加入手繪素材後不要使用 `--overwrite`**，該參數會重建全部臨時素材。

本次已實際只換草地 PNG 為紫色測試圖塊：草地變色，山海、高度、側面與降雨保持正常；原圖已還原。

## 之後的瓶身與 UI 素材

七瓶目前為簡單 SVG 線條佔位。未來透明 PNG 建議共用一致畫布，約 160×240px，瓶口位置一致；瓶身／瓶蓋可分層，標示瓶口與旋轉支點。從 `LineArt.jsx` 替換，與地形／天氣分離。左側裝飾與結局小圖章可繼續用現有線條，不必新增大量插畫。
